🎵 Tango Music Score Generator v2
Windows EXE 사용 설명서

음원을 분석하여 탱고 리듬 트레이너에서 사용할 수 있는 OSZ 채보와 음악 분석 데이터를 자동 생성하는 프로그램입니다.

중요: 이 프로그램이 생성하는 music_score_v2.json은 실제 악보를 그대로 복원한 것이 아닙니다. 음원에서 추출한 BPM, beat, onset, 강세, 음역, 스펙트럼 등의 음악 구조 정보를 이용해 리듬게임용 채보를 생성합니다.

1. 실행

TangoMusicScoreGenerator.exe를 더블클릭합니다. 정상적으로 빌드된 EXE는 별도의 Python 설치 없이 실행할 수 있습니다.

2. 기본 사용 순서

  1. 음원 폴더의 찾아보기를 눌러 음원이 들어 있는 폴더를 선택합니다.
  2. 출력 폴더를 지정합니다. 기본적으로 입력 폴더 아래 charts가 사용됩니다.
  3. 처음에는 기본 설정을 그대로 사용하는 것을 권장합니다.
  4. ▶ 음원 일괄 분석 및 OSZ 생성을 클릭합니다.
  5. 하단 처리 로그에서 분석 및 생성 상태를 확인합니다.
  6. 완료 메시지가 나오면 출력 폴더에서 .osz 파일을 확인합니다.

3. GUI 옵션

항목설명
기본 LevelLv1/Lv2/Lv3 중 기본 채보 난이도입니다.
Modemusical, tango, beat, salient, instrument 중 분석/채보 방식을 선택합니다.
Lv1/Lv2/Lv3 모두 생성한 음원에서 세 난이도의 OSZ를 동시에 만듭니다.
모든 Mode 생성5개 Mode를 모두 생성합니다. 생성 파일 수가 크게 증가합니다.
하위 폴더 포함입력 폴더 아래의 하위 폴더까지 음원을 검색합니다.
Events CSV 생성추출된 음악 이벤트를 CSV로 저장합니다.
박자2/3/4박 기준을 선택합니다. 일반적인 탱고 음원은 기본값 4를 권장합니다.
Subdivision한 박을 2/4/8분할하여 이벤트 기준을 세분화합니다.
Offset(ms)채보 타이밍 전체를 밀리초 단위로 보정합니다.
Downbeat다운비트 기준을 직접 지정할 때 사용합니다. 일반적인 경우 공란으로 둡니다.
Pack 이름생성되는 OSZ의 팩 이름입니다.

4. Mode 설명

Mode특징
musical강세, 온셋, 음역 등 여러 음악적 특징을 종합합니다. 기본 모드입니다.
tango탱고 리듬에 맞는 이벤트 선택을 중심으로 합니다.
beat박자와 beat grid 중심의 채보입니다.
salient두드러지는 온셋/강세 이벤트 중심입니다.
instrument음역과 역할별 이벤트 분류를 활용합니다.

5. 난이도

  • Lv1: 비교적 단순한 리듬 이벤트 중심
  • Lv2: 중간 밀도의 음악 이벤트
  • Lv3: 더 촘촘하고 많은 이벤트

6. 출력 파일

Mi dolor - music_score_v2.json
Mi dolor - musical-Lv1.osz
Mi dolor - musical-Lv2.osz
Mi dolor - musical-Lv3.osz
Mi dolor - events.csv

CSV는 해당 옵션을 선택했을 때만 생성됩니다. JSON은 음악 분석 결과를 확인하거나 이후 분석/채보 시스템을 확장할 때 사용할 수 있습니다.

7. OSZ 사용

생성된 .osz 파일은 기존 Tango 리듬 트레이너 HTML에서 불러올 수 있습니다. OSZ에는 채보 파일(.osu)과 분석 대상 음원이 함께 들어갑니다.

9. 오류가 발생할 때

ModuleNotFoundError: No module named 'librosa' 등이 EXE 실행 중 발생한다면 EXE 빌드에 필요한 분석 라이브러리가 포함되지 않은 것입니다. 배포할 때는 의존성 수집이 적용된 최신 빌드로 다시 생성해야 합니다.

특정 음원에서만 오류가 발생한다면 처리 로그와 해당 음원의 파일 형식을 확인합니다.

10. 프로그램의 기술적 한계

현재 버전은 음원에서 실제 악보를 완전하게 전사하는 시스템이 아닙니다. BPM/beat/onset/강세/음역/스펙트럼 등의 특징을 분석하여 '악보에 가까운 구조 데이터'를 만들고, 이를 리듬게임용 채보로 변환합니다. 실제 연주자의 정확한 멜로디, 화음, 악기별 음표와 완전히 일치하지 않을 수 있습니다.
